# eagleeyes

Eagle Eye — Premium Security & Automation Systems website.

## Overview
Eagle Eye provides smart security, high-definition CCTV surveillance, intelligent automation, structured networking, biometric access control, and 24/7 technical support.

## Tech Stack
- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS (Modern dark glassmorphic design inspired by ibii.dev)
- **Deployment:** Vercel ready (`vercel.json`)

## Features
- Modern Hero Section with badge and quick contact CTAs
- Comprehensive Services Showcase (CCTV, Biometrics, Smart Automation, Networking, Intercom & Fire Alarms)
- About & Trust Metrics (10+ Years, 500+ Projects, 99.9% Uptime)
- Interactive Contact / Booking / Consultation forms with WhatsApp integration
- QR Code Ready: Link your printed business QR codes directly to the deployed site
- Fully responsive across desktop, tablet, and mobile

## Local Development
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```
